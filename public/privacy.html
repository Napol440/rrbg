Rocket Rebound — Privacy Policy

Last updated: September 2026

1. Data we process

To run multiplayer rooms we process, in memory only: your display name, Discord user ID and avatar (when playing inside Discord), moves and solutions submitted during a round. No accounts, no passwords, no persistent profiles.

2. Storage and retention

Room data lives in server memory and is deleted when the room empties or the server restarts. Nothing is sold or shared with third parties. Discord OAuth tokens are exchanged server-side and never logged or stored.

3. Cookies and tracking

We set no cookies and use no analytics or advertising trackers.

4. Children

The game is intended for use via Discord and is subject to Discord's age requirements.

5. Contact

Questions: via the repository issue tracker.
